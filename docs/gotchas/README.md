Si te encuentras con una nueva, apúntala en el mismo PR.

## Formato

```md
### Título corto que se pueda buscar

- **Síntoma:** qué se ve cuando pasa.
- **Causa:** por qué pasa.
- **Solución:** qué hacer (o qué no hacer).
- **Ref:** ADR, fichero o enlace (opcional).
```

Si un gotcha deja de aplicar, bórralo: una lista con trampas que ya no existen confunde más que ayuda.
