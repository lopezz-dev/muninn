# Notas

> **Estado:** ya puedes crear y buscar notas a través de los [asistentes de IA](06-asistentes-ia.md).
> El editor visual llegará próximamente.

Las notas sirven para todo lo que no es una tarea: ideas, actas de reuniones, documentación de un proyecto…

- Se escriben en **Markdown** (títulos, listas, código, enlaces…).
- Pueden ser **sueltas** o estar **vinculadas** a un proyecto o a una tarea concreta.
- Las **fijadas** aparecen siempre arriba. Después van las más recientes.
- **Búsqueda** por título y contenido.
- **Archivar** una nota la oculta sin borrarla.
