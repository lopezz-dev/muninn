# Bienvenida a Muninn

Muninn es tu **sistema operativo personal**: un único lugar para los proyectos, las tareas, las notas
y, pronto, tus finanzas. Además, un asistente de IA conoce todo ese contexto y puede contarte cómo vas.

El nombre viene de la mitología nórdica: Muninn (la memoria) era uno de los dos cuervos de Odín, que
volaban cada día por el mundo y volvían a contarle lo que habían visto. Muninn recuerda por ti.

## Cómo está organizado

Muninn se compone de **módulos** que puedes activar o desactivar según lo que necesites:

| Módulo | Para qué sirve |
|---|---|
| **Tareas** | Proyectos con su tablero Kanban, totalmente personalizable |
| **Notas** | Apuntes en Markdown, sueltos o vinculados a un proyecto o tarea |
| **GitHub** | Tus issues se convierten en tareas del proyecto correspondiente *(próximamente)* |
| **Finanzas** | Gastos, ingresos, ahorro, inversiones y suscripciones *(próximamente)* |
| **Noticias** | Resúmenes de las fuentes que te interesan *(próximamente)* |
| **Concentración** | Temporizador para bloques de trabajo profundo *(próximamente)* |

## Dónde puedes usarlo

- **Escritorio:** Windows, macOS y Linux.
- **Móvil:** como app instalada desde el navegador (iPhone y Android).
- Todo se **sincroniza** entre tus dispositivos.
