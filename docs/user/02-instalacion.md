# Instalación

> **Próximamente:** la primera versión instalable se publicará cuando esté lista la interfaz.
> Esta página describe cómo será el proceso.

## Escritorio

Descarga el instalador de tu sistema desde la página de versiones (Releases):

| Sistema | Fichero |
|---|---|
| Windows | `Muninn_x.y.z_x64-setup.exe` o `.msi` |
| macOS (Intel y Apple Silicon) | `Muninn_x.y.z_universal.dmg` |
| Linux | `.AppImage` (portable) o `.deb` (Debian/Ubuntu) |

En macOS, si la versión no está firmada, la primera vez abre la app con **clic derecho → Abrir**.

## iPhone

Muninn se instala desde Safari como una app más, sin pasar por la App Store:

1. Abre la dirección de Muninn en **Safari**.
2. Pulsa el botón **Compartir** (el cuadrado con la flecha).
3. Elige **Añadir a pantalla de inicio**.
4. Abre Muninn desde el icono nuevo. Para recibir **notificaciones**, actívalas desde los ajustes de
   la app: en iPhone solo funcionan cuando está instalada así (iOS 16.4 o superior).

## Android

Abre la dirección en Chrome y pulsa **Instalar app** en el menú (⋮).

## Iniciar sesión

Usa la misma cuenta en todos tus dispositivos para que se sincronicen.
